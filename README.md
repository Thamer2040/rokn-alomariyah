# ركن العمارية

متجر إلكتروني بسيط للمجمدات والمواد الغذائية للمطاعم والمطابخ والكافيهات.

- المنتجات والصور: `app.js` / `images/`
- التنسيق: `styles.css` (بدون اعتماد خارجي)
- الهيكل: `index.html`

## المميزات

- عرض المنتجات حسب الفئة والبحث والترتيب
- سلة مشتريات تُرسل الطلب عبر واتساب
- وضع ليلي
- دعم كامل للجوال (عمودان)

## النشر

موقع ثابت — ارفع محتوى المجلد (المجلد `images` كامل) على أي استضافة ثابتة مجانية.
